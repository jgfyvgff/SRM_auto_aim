# Planner 云台反馈与响应时延记录（2026-10-27）

## 本次提交

- 真机配置新增 `planner_gimbal_response_delay_ms: 35`，单位为毫秒，合法范围 0–100 ms。
- Planner 扣除原有约 20 ms 的命令前视后，只对剩余滞后前推目标；当前 35 ms 配置对应额外约 15 ms。
- MPC 未收敛但诊断目标有效时，TX 回退使用与 MPC 命令相同的 20 ms 目标参考时刻。
- Planner 增加云台反馈对准误差与近未来参考误差诊断；两项均满足 `fire_thresh` 且 MPC 收敛时才申请开火。
- JSONL、离线回放和仿真探针增加对应的时延、目标、反馈及开火误差字段。
- 仿真探针将图像时刻的云台 TF 姿态按估计角速度外推到 Planner 计算时刻。
- 未修改下位机固件和串口协议。

## 已有离线证据

- 使用同一段 1200 帧回放对比额外补偿 0 ms 与配置 35 ms；两组 Tracker/Aimer 结果一致。
- 共有 1072 帧具备有效 Planner 结果。35 ms 组相对 0 ms 组的 TX yaw 命令差：中位数 0.094°、P95 0.167°、最大 3.213°。
- 较大的命令差集中在预测切板附近，仍有约 3° 的少数跳变；不能据此声称切板过渡已平滑。
- 35 ms 组收敛帧数从 759 降至 716，未收敛回退帧数增加 43；需结合真机反馈判断是否值得保留。
- 两组回放的 `planner_fire` 均为 0，且数据没有接近开火阈值的样本；该回放没有验证临界开火行为。
- 该离线回放没有云台实体，不能证明机械响应延迟、幅值衰减或闭环控制效果。
